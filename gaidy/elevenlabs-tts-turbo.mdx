# ElevenLabs TTS Turbo

Быстрый синтез речи.

```bash
curl -X POST "https://apia1.com/api/v1/audio/speech" -H "Authorization: Bearer <APIA1_API_KEY>" -H "Content-Type: application/json" -d '{"model":"<MODEL_ID>","input":"Добро пожаловать в APIA1","voice":"<VOICE_ID>"}' --output speech.mp3
```

Список voices, языков и аудиоформатов зависит от модели.
