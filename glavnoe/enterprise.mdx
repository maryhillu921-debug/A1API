# Для бизнеса

Для корпоративного использования разделяйте ключи по средам и сервисам, вводите лимиты расходов, журналируйте request metadata и используйте несколько провайдеров для критичных моделей.

## Рекомендуемая архитектура

`client -> ваш backend -> APIA1 -> provider`

Секреты остаются на backend. Для чувствительных данных заранее задайте допустимых providers и правила маскирования.
