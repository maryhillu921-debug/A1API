# APIA1 Proxy

Схема: `IDE/CLI -> localhost proxy -> apia1.com -> provider`. Proxy полезен клиентам, которые не умеют передавать расширенные routing/reasoning поля.

Слушайте только localhost, если прокси не предназначен для внешней сети, и держите API Key в env.
