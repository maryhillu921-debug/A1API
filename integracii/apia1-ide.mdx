# APIA1 IDE (alpha)

Десктопная IDE с AI-агентом.

## Базовая конфигурация

```text
Base URL: https://apia1.com/api/v1
API Key: <APIA1_API_KEY>
Model: <MODEL_ID>
```

Если клиент поддерживает OpenAI-compatible provider, этих параметров обычно достаточно. Если custom Base URL недоступен, используйте отдельный совместимый адаптер/APIA1 Proxy.

Сначала проверьте простой chat без tools, затем включайте agent-функции по одной. Не храните ключ в репозитории.
